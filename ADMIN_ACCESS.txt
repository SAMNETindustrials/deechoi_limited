HOW TO ACCESS THE ADMIN DASHBOARD
═══════════════════════════════════════════════════════════════════════════════

STEP 1: START THE SERVER
───────────────────────────────────────────────────────────────────────────────
Open terminal and run:

    cd /vercel/share/v0-project
    pnpm dev

The server will start on http://localhost:3000

═══════════════════════════════════════════════════════════════════════════════

STEP 2: NAVIGATE TO LOGIN PAGE
───────────────────────────────────────────────────────────────────────────────
Open your browser and go to:

    http://localhost:3000/admin/login

═══════════════════════════════════════════════════════════════════════════════

STEP 3: CREATE YOUR ADMIN ACCOUNT (First Time Only)
───────────────────────────────────────────────────────────────────────────────

On the login page, click "Sign Up" and enter:
  • Email: admin@deechoi.com (or any email)
  • Password: YourSecurePassword123!

Then:
  1. Click "Create Account"
  2. Check your email for confirmation link
  3. Click the link to verify email
  4. Return to login page
  5. Login with your email and password

═══════════════════════════════════════════════════════════════════════════════

STEP 4: YOU'RE NOW IN THE ADMIN DASHBOARD!
───────────────────────────────────────────────────────────────────────────────

You'll see:

WHAT YOU CAN DO IN EACH SECTION
═══════════════════════════════════════════════════════════════════════════════

STORE INVENTORY MANAGEMENT (Product Management)
────────────────────────────────────────────────

✓ View all products
✓ Add new products (name, price, description, category)
✓ Edit existing products
✓ Delete products
✓ Manage stock quantities
✓ Toggle in-stock status
✓ Set product categories
✓ Upload/add product images

Products you add here IMMEDIATELY appear on the storefront homepage!


STOCK INVENTORY MANAGEMENT (Raw Materials)
───────────────────────────────────────────

Contains TWO tabs:

TAB 1: STOCK ITEMS
  ✓ Track raw ingredients (Fish, Meat, Pepper, Onions, etc.)
  ✓ Add new stock items
  ✓ Monitor current quantities
  ✓ Set unit prices
  ✓ Define reorder levels
  ✓ Manage supplier information
  ✓ Get alerts when stock is low

TAB 2: RESTOCK INVOICES
  ✓ Create purchase orders for raw materials
  ✓ Select items to reorder
  ✓ Specify quantities needed
  ✓ System calculates total cost
  ✓ Generate PDF invoices
  ✓ Download for purchasing team
  ✓ Track invoice status

QUICK EXAMPLE WORKFLOW
═══════════════════════════════════════════════════════════════════════════════

ADDING YOUR FIRST PRODUCT:
────────────────────────

1. Click "Store Inventory Management"
2. Click "Add Product"
3. Fill in:
   • Name: "Jollof Rice"
   • Price: "2500"
   • Description: "Delicious rice with vegetables"
   • Category: "Rice & Foods"
   • Stock Quantity: "20"
   • In Stock: Toggle ON
4. Click "Save Product"
5. DONE! Product now appears on homepage

────────────────────────────────────────────────────────────────────────────────

CREATING A PURCHASE ORDER:
──────────────────────────

1. Click "Stock Inventory Management"
2. Click "Stock Items" tab (if not already there)
3. Add your raw materials first:
   • Name: "Fresh Fish"
   • Unit: "kg"
   • Current Quantity: "50"
   • Unit Price: "3500"
   • Reorder Level: "20"
   • Supplier: "Local Fish Market"
4. Save item
5. Click "Restock Invoices" tab
6. Click "Create New Invoice"
7. Select items you need (Fish, Meat, Pepper, etc.)
8. Enter quantities
9. Click "Generate Invoice"
10. Click "Download PDF"
11. Share with purchasing team

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Can't login?
  → Check that email is confirmed
  → Look in spam folder for confirmation email
  → Try creating a new account

Products not showing on storefront?
  → Check "In Stock" toggle is ON
  → Make sure category is filled in
  → Wait 2-3 seconds for real-time sync

Can't see the page?
  → Ensure server is running (pnpm dev)
  → Check browser console for errors
  → Try http://localhost:3000 first
  → Clear browser cache

Forgot password?
  → Use Supabase "Reset Password" link on login page
  → Check spam folder for reset email
